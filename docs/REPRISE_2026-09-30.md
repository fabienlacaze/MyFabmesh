## Piste en cours : 3D locale impossible sur un Python embarqué
Triton compile un lanceur natif au premier usage. Le Python embarqué (`%APPDATA%\myfabmesh-ai\python`) n'a **ni `Include` ni `libs`** : `tcc` (et `cl.exe`) échouent. Test local : copier `Include` d'un Python 3.11 complet dans `python/Include` -> la commande `tcc` réussit à la main (EXIT 0). Reste à confirmer une 3D complète, puis à décider comment livrer `Include` (+ éventuellement un cache Triton précompilé) avec l'appli. `tcc.exe` (non signé) a été bloqué une fois par Smart App Control (WinError 4551) puis autorisé : comportement non stable.

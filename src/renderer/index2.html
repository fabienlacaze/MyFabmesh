Frees memory while the PC generates: turns on the three options below. Some tools take a few seconds longer to restart.
Eco mode turns on
Free the app's graphics memory while a generation runs
The 3D viewers go blank until the generation is done, which gives the calculation up to 1 GB more. They come back by themselves.
Unload the image engine before a 3D, rig or animation
It keeps its models in graphics memory for up to 5 minutes after the last image. The next image takes a few seconds longer to start.
Pause the translator and the writing assistant during a generation
Gives back 1 to 4 GB of memory. Automatic descriptions are slower to start during the generation.
Offer eco mode when memory is tight

What's this?

Claude & scripts

        
      

      
Claude or your scripts can create projects, images, 3D models and rigs for you. MyFabmesh.AI must stay open.

      
The access key is a password that MyFabmesh.AI creates by itself at each start. You do not set it: Claude reads it on its own. Only your own scripts need to copy it.

Safety

        
    
          
  • Off by default. Only programs on this PC can connect, and only with the access key.
    • 
          
  • Whoever has the access key can use the app like you, cloud credits included.
    • 
          
  • A new access key is made at each start. Turn the switch off when you are done.
    • 
          
  • With automatic connection, access is turned on at each start of MyFabmesh.AI.
    • 
        


        
Trouble?

        
    
          
  • No “fabmesh” in Claude: quit Claude Desktop completely and reopen it.
    • 
          
  • “Not reachable”: open MyFabmesh.AI and turn the switch on.
    • 
          
  • “Port 7331 is busy”: another copy of MyFabmesh.AI is already running.
    • 
          
  • Status “Linked to another copy”: click Connect Claude Desktop again.

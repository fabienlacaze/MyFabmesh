# Politique de securite / Security policy

## Signaler une vulnerabilite (FR)

Si vous pensez avoir trouve une faille de securite dans MyFabmesh (site web,
application de bureau ou API), merci de nous l'ecrire a
**myfabmesh.contact@gmail.com** avec :

- une description du probleme et de son impact ;
- les etapes pour le reproduire (adresse, requete, capture) ;
- votre contact si vous souhaitez un retour.

Merci de ne pas ouvrir de ticket public pour une faille non corrigee : le depot
est public.

Engagements :

- accuse de reception sous **7 jours** ;
- information sur l'avancement de la correction ;
- pas de poursuites pour une recherche de bonne foi : pas d'acces aux donnees
  d'autres utilisateurs au-dela du necessaire pour prouver la faille, pas de
  deni de service, pas de destruction ni d'exfiltration de donnees.

## Reporting a vulnerability (EN)

If you believe you found a security issue in MyFabmesh (website, desktop app or
API), please email **myfabmesh.contact@gmail.com** with a description, impact and
reproduction steps. Please do not open a public issue for an unfixed
vulnerability, as this repository is public.

We acknowledge reports within **7 days** and keep you informed of the fix. We
will not pursue good-faith research that avoids other users' data, service
disruption and data destruction.

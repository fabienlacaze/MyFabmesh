🚨 Service kill switches

Cuts off Modal GPU calls or the entire site if something's on fire. Re-enter your admin password to unlock the toggles.

Forgot password?

🎚️ Master switch
One click flips Modal + Stripe + Site + Marketplace together.

🔥 Warm containers

Wake the GPU containers now, so the next generation does not wait for a cold start. Each one stays warm for a few minutes after its last call and costs a few cents of GPU.

🔁 Force logout

Invalidates every active Supabase session in one click. Users see a "session expired" error on their next request and land back on /login. Your own admin session is preserved.
